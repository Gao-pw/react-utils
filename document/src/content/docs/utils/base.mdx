*@siroi/fe-utils* 是 *@siroi/react-utils* 的上层依赖，包含了许多不限框架的 *native method* 😋，您可以直接安装进行使用

<Aside type="caution">
该库暂时没有提供类似 **CMD** 的直接引用方法。请使用 **ESM** 的方式调用这个方法库，该库的文档也托管在此
</Aside>

推荐使用 **pnpm** 进行安装使用

```bash
pnpm add @siroi/fe-utils
```
